# ByKaranteli

A crypto-derivatives market-structure data service built on a deterministic crypto-futures signal engine. Its free, no-key public REST API surfaces funding rates/arbitrage, open interest, liquidation maps, options (Deribit), ETF flows, order-flow toxicity (VPIN), Coinbase premium, CFTC COT positioning, and Fear & Greed / BTC-dominance indices, plus live signal performance and per-symbol/strategy leaderboards. It also offers a hosted MCP server, x402 agent-payment endpoints, and CC0 datasets.

## APIs

- **ByKaranteli Public Data API** — Read-only, no-key REST/JSON API for crypto derivatives market-structure data: funding rates/arbitrage, open interest pressure, liquidation maps, options, ETF flows, VPIN toxicity, Coinbase premium, COT positioning, market indices, signal performance and leaderboards. CORS-enabled, 20 req/min/IP, JSON and CSV output. (`https://bykaranteli.com/api`)

> REST API, hosted MCP server (https://mcp.bykaranteli.com), llms.txt and openapi.json are all confirmed via the provider's developer page, apis.json (spec v0.21), well-known pre-detector, and GitHub repos. A local MCP option also exists via 'npx -y bykaranteli-mcp' (source: https://github.com/bykarantelicom/bykaranteli-mcp, MIT) — not cataloged as MCPServer since it is a locally-installed CLI. MCP server ships 20 read-only tools per the README/apis.json (the /developers page stale-states 10). x402 agent-payment endpoints (/api/x402/liqmap-levels, /api/x402/options-flow, /api/x402/flow-vpin) settle in USDC on Solana/Base with a machine-readable catalog at https://bykaranteli.com/api/x402. CC0 datasets at https://github.com/bykarantelicom/crypto-datasets. Raw JSON artifacts (apis.json, openapi.json, llms.txt, /api/x402) could not be independently re-fetched in-session due to non-HTML fetch blocking, but nothing contradicted their declared existence.
